# 真基准完整实验 · 结果摘要

## 实验设计（预注册，非事后调参）

- **研究问题**：合成实验得到的四条结论，在真实 MOT 基准上是否成立。
- **数据**：DanceTrack val (25 序列)、MOT17 train / FRCNN (7 序列)、MOT20 train (4 序列)。
- **输入口径**：三个基准统一使用「按 TrackEval 口径过滤后的 GT 框」作为检测输入（conf≠0 且 class=1），即 oracle-detection / association-only 设定。理由：DanceTrack 官方 val 不提供 det.txt，若混用公开检测器输出会造成口径不一致；本研究考察关联策略而非检测器质量。**局限**：检测完美使 DetA 接近 1，结论不能直接外推到含误检/漏检的真实检测输入。
- **ReID**：OSNet-x1_0 (MSMT17)，512 维，L2 归一化，FP32，一次抽取并缓存；所有策略共享同一份特征，排除预处理差异。
- **跟踪器**：在线逐帧，线性速度预测 + IoU 门控 + 匈牙利匹配；模板取可信前缀 10 帧均值并冻结（在线更新仅作消融）。
- **对照**：S0 motion-only / S1 逐帧全局外观 / S2 候选数门控 / S3 混淆风险触发+成对差异仲裁。
- **消融与扫描**：历史 AUC 置信度 vs 当前帧校准、在线模板更新、饱和触发、禁用弃权、τ 网格（预算曲线）、α 外观权重网格、5 个随机种子。
- **GT 使用边界**：跟踪器全程不接触 GT 身份；GT 身份仅在事后用于可分性分层与正确性核算。
- **统计**：序列级有放回 bootstrap 1000 次给 95% CI；判定阈值在跑实验前写入 exp_config.py。
- **主指标**：TrackEval 官方 HOTA / AssA / DetA / IDF1 / IDSW / MOTA；分层与预算曲线使用逐帧 IDSW（自实现，口径独立于官方汇总）。
