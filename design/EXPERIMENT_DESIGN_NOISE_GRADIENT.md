## 0. 关于「无人做」的诚实声明

关于研究定位，需先说明三点：

1. **无法证明世界上无人做过**。本次是系统化多源检索（2 路综述式检索 + 9 组定向检索 +
   3 篇原文/摘要抓取），不是系统综述；未逐篇筛引文网络、未覆盖所有措辞。
   「未检到」≠「不存在」。
2. **查新核实的几处判断**：
   - 「连续噪声轴没人做过」→ 不成立，DiffusionTrack 已有相关工作；
   - 「把检测噪声做成自变量是空白」→ **部分被占**，已有 Robustness Score / Breaking Point；
   - 「PPLR 搬到在线 MOT 没人做过」→ 不成立，CropTrack 已有相关工作；
   - 「时间相关的检测失败没人建模」→ 不成立，已有显式建模工作，本设计不把它作为首创性主张。
3. 因此本设计不主张「机制新颖」，而主张一个**更严格、可证伪的组合判据**：
   在可检索范围内，未检到同时满足下列四条的工作
   （a）检测噪声按正交分量连续标定并扫描；
   （b）响应量是「精细关联相对 IoU 基线的**边际关联增益**」而非 tracker 整体指标；
   （c）形式化定义收益的**符号翻转边界**并测绘；
   （d）给出**评测前、无需标签**即可预测该收益符号的判据，并做留一外部验证。
   证伪条件见 §7.3。

## 2. 研究问题与预注册假设

- **RQ1（曲面）**：精细关联相对 IoU 基线的边际增益 `ΔAssA` 如何随检测噪声的正交分量变化？
  是否存在符号翻转边界，且边界按噪声分量可分解？
- **RQ2（主问题，预测性）**：能否在**不跑评测、不用 GT 标签**的前提下，仅从检测输出的可观测量
  预测某个（数据集, 检测器）组合上 `ΔAssA` 的符号与量级？该预测能否跨数据集、跨检测器迁移？
- **RQ3（归因）**：文献报告的关联增益（如 VLA-ReID +1.1 HOTA、When-to-Extract 的精度略升）
  在曲面上位于哪个噪声区间？其增益有多少可归因于检测噪声而非关联机制本身？

| 编号 | 预注册假设 | 零假设 / 判定方向 |
|---|---|---|
| H1 | `ΔAssA(Θ)` 对至少一个噪声分量非单调，存在可定位的 `η*_0`（边际收益归零点）与 `η_flip`（转负点） | H1₀：`ΔAssA` 在全域单调或恒 ≤0；若成立，得到"不存在正收益窗口"的定量边界结论 |
| H2（主） | 留一验证下，无标签判据对 `ΔAssA` 符号的预测准确率显著 > 0.5，且显著优于简单基线（仅检测置信度 / 仅 FN/FP 率） | H2₀：不优于 0.5 或不优于基线；若成立，得到"关联收益不可先验预测"的校正性结论 |
| H3 | 边界位置可由分量分解解释：`σ_loc` 主要影响 IoU 基线的可修错误，`λ`（FP）主要影响误干预代价，二者对 `ΔAssA` 的偏导符号相反 | H3₀：分量效应不可分离或同号 |

**关键设计原则**：三条假设无论成立与否，均产出可报告的结论（见 §6.2）。

## 3. 形式化定义

### 3.1 检测噪声四元组与标定

从 GT 框出发施加**正交可控注入**（不依赖任何真实检测器即可完整控制）：

```
Θ = (σ_loc, β, λ, τ)
  σ_loc : 框中心/尺度高斯扰动，按目标高度归一化（单位：目标高度的 %），消除尺度与帧率依赖
  β     : 按目标随机删除比例（FN），控制漏检率
  λ     : 按帧随机插入虚警比例（FP），虚警位置从背景/邻域采样，附置信度分布
  τ     : 失败的时间相关长度（连续 L 帧保持同一失败状态），L=1 即独立注入
```

**标定协议**：对 MOT17 / MOT20 的官方 `det.txt`（现成，MOT17 42 个 / MOT20 8 个），用同一套
估计量反解其 `Θ̂`，把注入档位映射到"等价于真实检测器"的坐标。这样曲面可与真实 det 对齐，
且**不需要为 DanceTrack 训练或下载 YOLOX 检测**（DanceTrack 官方无 det）。

> τ 只作为控制变量（已有工作建模过持续性失败，见 §1.1），不主张其新颖性。

### 3.2 响应量（核心，与竞品的分水岭）

```
ΔAssA(Θ; s) = AssA(strategy=s, Θ) − AssA(strategy=SORT-IoU, Θ)
ΔIDSW(Θ; s) = IDSW(s, Θ) − IDSW(SORT-IoU, Θ)      # 负值为好
```

主指标用 **AssA / IDSW / IDF1**，不用 HOTA 或 MOTA：噪声升高主要打击 DetA，而关联策略只作用于
AssA，几何平均结构会天然压低关联收益的可见度（依据 HOTA 原文）。DetA、Frag、FPS/ReID 调用次数作次要读出。

### 3.3 三个边界量

| 记号 | 定义 | 含义 |
|---|---|---|
| `η*_0` | 使 `∂ΔAssA/∂η = 0` 的点 | 精细关联的边际收益归零 |
| `η†` | 使 `|ΔAssA(η)| < |ΔDetA(η)|` 的最小 η | 关联收益被检测退化吞没，任何指标上都不可见 |
| `η_flip` | 使 `ΔIDSW > 0` 的最小 η | 精细关联开始**主动制造** ID 切换（误干预主导） |

### 3.4 无标签先验判据

可观测量向量 `Φ`（全部只需检测输出与少量帧统计，**不需要 GT、不需要跑 TrackEval**）：
候选代价矩阵 top-1/top-2 边际分布；帧内检测框 Jaccard 重叠分布；候选集内 OSNet 特征
cosine 边际与共模能量占比；框分数分布；`Θ̂` 的无标签估计；检测消失/重现游程长度。

判据 `P(Φ) → sign(ΔAssA), |ΔAssA|`。**与 When-to-Extract / Deep OC-SORT / AAI 的根本区别**：
它们是帧级"这一帧用不用外观"，`P` 是数据集/检测器级"这套精细关联总体值不值得部署"。

## 4. 实验设计

### 4.1 数据与输入

| 基准 | 序列 | 用途 |
|---|---|---|
| MOT17 | 7 个 FRCNN 序列（官方 42 个 det 用于 Θ 标定） | 主分析 + 真实 det 锚点 |
| DanceTrack | 25 个 val 序列 | 外观高度同质性 + 非线性运动；只用 GT 注入，不用 det |
| MOT20 | 4 个 train 序列（8 个官方 det） | 高密度拥挤；外部验证集 |

**DanceTrack 无官方 det 不再成为障碍**：本设计从 GT 注入噪声，官方 det 只用于把注入坐标
标定到真实检测器水平。

### 4.2 噪声网格（Phase 0 已冻结，`hybrid_v1`，28 个条件）

`frozen_config.json` 以 SHA-256 封装，任何后续改动都会被 `verify_frozen()` 检出。
枚举规则见 §9 与 `det_calibration.build_grid()`；**先冻结、后跑实验，不据结果增删**。

| 分量 | 冻结档位 | 说明 |
|---|---|---|
| `σ_loc` | `0, .02, .032002, .05, .10, .20` | 第 4 档为实测 P75；末档为设计稿预设 20% 目标高上界 |
| `β` | `0, .05, .10, .20, .431925, .75` | 第 5 档为实测 P50（真实 FRCNN/SDP/DPM 典型漏检率） |
| `λ` | `0, .05, .10, .20, .301718, .50` | 第 5 档为实测 P90 |
| `τ` | `1, 10, 25` | `1` + 实测 P50/P90 的连续漏检游程（帧） |

- 单因子 17 个 + τ-only 2 个 + 交互 8 个 + 全零基线 1 个 = **28 个唯一条件**。
  全零基线在单因子扫描中重复出现，去重后为 28 个唯一条件。
- 交互子网格：`σ_loc×λ`、`β×λ`、`τ×β`，各用「中档 × 高档/真实档」配对，
  保证交互可观测，而非全挤在干净区。
- **为什么不用纯分位数**：真实 det 的 β 中位数 0.432、P10 也有 0.297，
  纯分位数会完全跳过 `β∈(0, .39)`，而那正是最可能存在正收益窗口的区间。
  故采用「设计稿低档 + 一个分位数锚点 + 预设极端上界」的混合规则。
- **跨源校验**：本机原版 `MOT17.zip` 与服务器 hf-mirror 重打包数据反解的 25 个 Θ̂
  逐字段零差异（`phase1_server_report.json`: `CROSS_SOURCE_CALIBRATION_OK`）。

### 4.3 策略族（只换关联门控，其余全部固定）

| 代号 | 策略 | 说明 |
|---|---|---|
| `A0` | SORT / IoU-only | 基线，所有 Δ 的参照 |
| `A1` | ByteTrack 式两阶段低分复用 | 吸收漏检 |
| `A2` | 外观融合（OSNet + 匈牙利） | 常规精细关联 |
| `A3` | 本项目原 PDE 仲裁 / 混淆风险触发 | 复用已有代码，作为阴性对照 |
| `A4` | 交叉一致性弃权（Jaccard 门控） | **仅作为被测机制，不宣称新颖**（PPLR/CropTrack/AAI/LLTrack 已覆盖其构件） |
| `A5` | set-relative 残差重打分 | 复现 VLA-ReID 思路（无需训练，用 CAS 近似），用于 RQ3 归因 |

外观特征统一用现成 `osnet_x1_0_msmt17.pth`（FP32，跨帧攒批）。换框后 `.npy` 缓存全部作废，
按 `(数据集, 噪声条件, 序列)` 为 key 重抽。

### 4.4 两阶段抽样（防过拟合 / 防数据泄漏）

| 阶段 | 数据 | 用途 | 约束 |
|---|---|---|---|
| 探索 | 每基准抽 5 个序列 × 前 500 帧 | 拟合 `P`、估计 `η*_0 / η† / η_flip` 的粗位置 | 只用于建模 |
| 确认 | 全部序列全帧 | 在**冻结的**判据与边界点上做一次性验证 | **不再调参、不再换阈值、不再增删条件** |

判据 `P` 只用一个轻量模型（逻辑回归 / 小梯度提升，特征数 ≤8），避免用大模型把噪声记住；
报告特征消融，给出"最小充分统计量集合"。

### 4.5 统计与多重比较

- 每个格点 ≥3 个随机注入种子；`ΔAssA` 用 bootstrap（≥1000 次重采样）给 95% CI
- 主分析只有 H1/H2/H3 三条，用 Holm 校正；其余一律标为探索性、不进结论
- 留一验证三种：**留一数据集**、**留一检测器（官方 det 来源）**、**留一噪声分量族**
- 与简单基线比较：仅检测置信度、仅 β/λ、恒定预测多数类
- 报告符号预测准确率、AUC、校准误差；CI 不含 0.5 才算 H2 成立
- 质量门：复用已修好的 `idsw_consistency`（`prev.update(cur)` 版，本机预演自实现 15 = 官方 15）；
  换 det 框后 GT 身份回映射口径必须重做并重验

## 5. 预注册判定规则

| 假设 | 成立时需满足 | 成立时的结论 | 不成立时的结论 |
|---|---|---|---|
| H1 | 至少一个分量的 `ΔAssA` 非单调，且 `η*_0` 的 bootstrap CI 有限 | 给出"关联收益窗口"的定量宽度与按分量分解 | 证明全域不存在正收益窗口，给出上界；解释 oracle-detection 下触发率 1.2% 的结构性原因 |
| H2 | 三种留一验证下符号准确率 CI 下界 > 0.5，且优于简单基线 | **关联收益可从无标签观测量先验预测**，给出最小充分统计量；可直接指导"要不要部署 ReID" | **关联收益不可先验预测**，定量给出失效场景；校正 Deep OC-SORT / selective ReID / AAI / Sentinel 隐含的"歧义度即可信度"前提 |
| H3 | 分量偏导符号相反且 CI 不重叠 | 回答"关联到底在补偿哪类检测噪声" | 证明分量效应不可分离，现有单一扰动鲁棒性曲线不足以刻画关联价值 |

**两个口径都报告**：注入口径（内部效度）+ 官方 det 锚点口径（外部效度）。禁止只报好看的那个。
η 是 Phase 0 冻结的连续自变量，不是看到阴性结果后临时换口径，避免结果驱动的口径搜索。

## 6. 研究定位与价值

### 6.1 三条贡献（按可辩护性排序）

1. **C1 方法学**：检测噪声的正交标定与注入协议（σ_loc / β / λ 可分解、与真实 det 对齐、按目标尺度归一）。
   现有加噪工作或单一位置扰动、或图像级退化，噪声量纲不统一，跨论文不可比。
2. **C2 定量边界**：以「相对边际关联增益」为响应量的响应面，以及 `η*_0 / η† / η_flip` 三个可操作的边界量。
   DiffusionTrack 有曲线无边界；Ma et al. 有量级无梯度；oracle 系列是二元。
3. **C3 主贡献 — 可预测性结论**：评测前、无标签的收益符号预测 + 留一外部验证。
   这是文献中未检到的、且**正负都有结论**的科学问题；也是与所有帧级门控工作的分界线。

**明确不主张的新意**：交叉一致性弃权、差异指纹、分模块 Jaccard、共模残差、在线弃权、
连续噪声曲线、Breaking Point、oracle 分析——全部已有先行工作，仅作为对照或被测机制。

### 6.2 两种结果方向的结论价值

- 若 H2 成立：得到一个可迁移判据，工程师在部署前即可判断"这个场景要不要上 ReID/复杂关联"，
  直接把 selective ReID 的省算力思路从帧级前移到系统级；并解释某类方法在不同数据集上的增益差异。
- 若 H2 不成立：得到一个**校正性负面结论**，说明"用简单歧义度决定关联复杂度"这一被多篇工作
  默认的前提不成立，并给出失效边界。
- 无论哪种：都定量回答 RQ3——文献报告的关联增益有多少其实来自检测噪声水平，
  补上 Ma et al. ">10% vs <5%" 之后的归因空白。

## 9. 设计决策

以下五项决策已写入 `code/noise/frozen_config.json` 并以 SHA-256 封装。

| # | 决策 | 理由 |
|---|---|---|
| 1 | **接受「边界 + 可预测性」为主研究问题** | 查新后机制层面空间有限；该定位在两种结果方向下均可产出结论 |
| 2 | **MOT17 + DanceTrack 主分析，MOT20 外部验证** | DanceTrack 用 GT 注入绕开「无官方 det」；MOT20 专用于留一数据集验证，不参与主假设拟合 |
| 3 | **纳入 `A5`，但降为探索性** | 只在 MOT17 探索子集用于 RQ3 归因，不进 H1/H2/H3 与 Holm 族——强化归因结论而不增加多重比较负担 |
| 4 | **两阶段抽样 + Phase 0 冻结** | 防 p-hacking 的核心；额外加 SHA-256 封装，每阶段启动时校验，避免口径漂移 |
| 5 | **立即写配置与代码** | 代码与冻结配置已归档；确认阶段未启动 |

两项额外的设计约束（均在任何 GPU 结果之前）：
- **留一验证分层**：留一数据集 / 留一检测器为主验证；留一噪声分量族降为次要读出（样本量小、CI 宽，易出假阴性）。
- **判据 `P` 只用逻辑回归、特征 ≤8**：比梯度提升更抗过拟合，且系数可直接回答 H3 的「分量效应是否可分离」。
