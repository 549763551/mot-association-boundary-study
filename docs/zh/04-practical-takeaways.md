# 04 · 可落地结论与它们的边界

[返回主入口](../../README.md) · [English](../en/04-practical-takeaways.md)

> 全部读数均受 `final_decision = null` 限制。下文按「可写入代码 / 可改变工程决策」与「不可直接部署」分层列出，并标明每条结论的适用范围。

## 第一档：可直接使用的实现规范（省成本 / 防错）

| 结论 | 实际怎么用 | 用不了的地方 |
|---|---|---|
| **真实 det 的噪声以时间相关漏检为主**：框抖动中位数 0.020（2% 目标高），漏检率 0.432、连续漏检游程约 10 帧 | 资源投向依据：优先投入**检测端的时序恢复 / 遮挡期间轨迹 keep-alive / 重检测召回**，而不是再调框对齐或加精细外观打分。100 px 高的行人框位置误差中位数约 2 px，几何侧改进空间有限 | 这是 MOT17/MOT20 **官方 det** 的画像，不是所有检测器；现代 YOLOX 系跟踪器的噪声结构未必一样；只统计了 25 个 TRAIN 序列 |
| **MOT20 `det.txt` 第 7 列是 0/1 有效性标志，不是置信度**；MOT17 的 21 个 det 才有连续分数 | 写进数据加载器：按列语义分流，不把 MOT20 的 0/1 当 score 喂给门控或排序 | 纯解析规则，不改变模型精度 |
| **`geometry_keyed_v1`**：只有 `σ_loc` 改框几何，β/λ/τ 下存活 TP 框与 GT 逐位相同 | 做噪声鲁棒性评测/消融时，按「几何是否变化」给特征缓存打 key。本项目 28 个条件里只重抽 9 个 | 省的是**实验算力**，不是线上推理成本 |
| **评测实现的三条规则**：官方 HOTA 用 `global_alignment×IoU` 匹配，TP 集合随 tracker id 分配变化；`A1` 丢低分框会让 `DetA` 不可比；扰动后身份回映射须使用 `src_gid` 旁路通道而非框坐标键 | 写 tracker 对比脚本时：检测集合不同就别直接比 HOTA/DetA，改报 `AssA` 并注明；注入类实验一律走原始 gid 旁路。配套的轻量 AssA/DetA 实现与官方 `eval_sequence` **diff = 0**，不必起整套 TrackEval 目录树 | 只管评测正确性，不改 tracker 本身 |

这四条构成可复用的实现规范：降低评测成本、避免口径错误，并给出资源投向依据。

## 第二档：只改变决策、不能部署的

- **「歧义度 ≠ 可信度」**：判据 `P` 留一 0.5512 低于简单基线 0.6071 / 0.6048。该结论为否定式指导——top-1/top-2 边际不宜作为 ReID 门控或置信度使用；它不提供替代方案，且是探索子集、未经正式判定，只能当弱证据。
- 文献侧 Ma et al. 的定量结论（检测器改进 >10% vs 精细关联 <5%）配合第一档的噪声画像，共同支持一个**优先级排序：先修检测、再谈关联**。这是排期依据，不是算法。

## 第三档：明确不能当工程参数用的

`η*_0` = 0.034 / 0.121 / 0.096、`η†` ≈ 0.02–0.05、`η_flip = 0` 这些边界量，**不能拿来设阈值**：

- 幅度全 < 0.013，28 个条件只有 6 个 CI 不含 0；
- 只跑了各 5 序列 × 500 帧；
- 没有 MOT20 留一外部验证、没有注入 / 官方 det 双口径、没有 Holm 校正。

它们现在的身份是**描述性读数**，不是标定结果。照着这个数去配系统，等于把探索阶段当确认阶段用。

## 另外一类可复用资产（与研究结论无关）

环境重建脚本（数据集由公开镜像直接下载）、按序列分片的结果同步、基于 OS 租约锁的备份守护。这些是工程资产，见 [`code/tooling/`](../../code/tooling/) 与 [复现文档](05-reproduction-and-archive.md)。

## 小结

本归档给出的结论均属「资源投向、算力节省、评测正确性、否定式指导」范畴，不包含可直接部署以提升跟踪精度的算法。
