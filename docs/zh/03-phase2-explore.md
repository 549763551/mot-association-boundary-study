## 2. 主响应量

cluster bootstrap，1000 次，按序列重采样：

| 量 | 均值 | 95% CI | 读法 |
|---|---|---|---|
| **`ΔAssA`** (A4−A0) | **+0.001832** | **[−0.000044, +0.004326]** | **含 0 → 平均无显著增益** |
| **`ΔIDSW`**（负为好） | **+31.43** | **[+25.03, +39.24]** | **显著为正 → 显著多出 ID 切换** |
| `ΔIDF1` | +0.002923 | [+0.000495, +0.005101] | 显著但幅度极小 |

`ΔAssA` 为正的组占 **49.76%**，几乎等同抛硬币。28 个条件里只有 6 个（c5/c19/c20/c23/c25/c26）的 CI 不含 0，且幅度全部小于 0.013。

## 3. 三个边界量

单因子曲线均从共用的 `η=0` 基线出发；`η*_0` 取 `∂ΔAssA/∂η = 0` 的首个内部极值，同时报告首次变号点（两者都给，不择优）。

| 分量 | `η*_0`（极值） | 变号点 | `η_flip` | `η†` | 内部极值 | `ΔAssA` 范围 |
|---|---|---|---|---|---|---|
| `σ_loc` | 0.0338 | 0.0210 | **0** | 0.02 | 是 | [−0.0272, +0.0137] |
| `β` (FN) | 0.1206 | 0.0299 | **0** | 0.05 | 是 | [−0.0097, +0.0051] |
| `λ` (FP) | 0.0960 | 0.2614 | **0** | 0.05 | 是 | [−0.0038, +0.0058] |
| `τ` | — | — | 1.0 | — | 否 | 恒 +0.0051 |

两点口径事实：

- **`η_flip = 0`**：无噪声 baseline 的 `ΔIDSW` 已是 **+0.6**，即「精细关联开始主动制造 ID 切换」在零噪声处就满足。这与实验 A 的 oracle 口径下「所有 `S3` 变体更差」方向一致。
- **`τ` 单因子完全退化**（c0 = c16 = c17 数值逐位相同）：τ 是失败状态的时间相关长度，当 `σ_loc = β = λ = 0` 时没有任何失败可关联，τ 自然无作用。这是**结构性事实**；τ 只在 `(τ × β)` 交互条件（c26/c27）里起作用。

`η†` 的可操作化定义为 `|ΔAssA| < |DetA(η) − DetA(0)|` 的最小 η。三个分量都在很低噪声处就满足，说明关联差异很快被检测质量退化淹没。

## 4. 判据 P（已冻结）

模型：L2 逻辑回归（L2=1.0，阈值 0.5，8 个无标签观测量，纯 numpy 实现以便服务器复现），拟合单元 840 组，目标 `sign(ΔAssA)`。

原始尺度系数：`mean_score +5.214`、`p10_score −1.084`、`score_gap +6.374`、`mean_pair_iou −10.609`、`det_per_frame −0.021`、`scale_cv −0.018`、`common_mode_energy −1.060`、`low_score_frac +4.705`；截距 `−3.075`。

**留一序列诊断（探索子集内部，仅拟合诊断，不是 H2 判定）**：

| 模型 | 符号准确率 | 95% CI |
|---|---|---|
| P（8 特征） | **0.5512** | [0.5190, 0.5857] |
| 基线：仅检测置信度 | **0.6071** | — |
| 基线：仅 β/λ 代理 | **0.6048** | — |
| 恒定多数类 | 0.5024 | — |

P 的 CI 下界虽 > 0.5，但**不优于任一简单基线**。按冻结的 `h2_rule`（须同时满足「CI 下界 > 0.5」且「所有主留一分折下优于每个基线」），**H2 倾向不成立**。

冻结文件：[`results/noise/frozen_criterion.json`](../../results/noise/frozen_criterion.json)，sha256 `47c32ece…8af1`，重跑可复现。

## 6. 口径事实

- 官方 HOTA 的匹配用 `global_alignment_score × IoU`，因此 **TP 集合会随 tracker id 分配变化**；即使注入框相同，各策略 `DetA` 也可差约 0.007。`A1`（ByteTrack）会丢弃低分框，同时改变检测集合，`DetA` 差异更大。这是官方定义；`ΔAssA` 仍为主响应，比较时须注明。
- 置信度池由全部 21 个 MOT17 TRAIN `det.txt` 按文件均匀采样、clip[0,1] 构成（15.6 万唯一值 / std 0.38）。MOT20 `det.txt` 第 7 列是 0/1 有效性标志、非置信度，故排除。
- `score_gap` 在冒烟单条件下为 0；全量探索数据中有 160 个唯一值 / std 0.0112，判据系数为 `+6.374`。
- 真实冒烟（MOT17-02-FRCNN / 200 帧 / cond18 `σ=0.05, λ=0.2`）：6 策略 AssA 全不同，`n_amb ≈ 5909`，A4 弃权 21635 次 → 网格存在可测信号。

## 7. 分析脚本口径

1. 单因子曲线按预注册定义判定，须同时满足 `tau == 1` 约束；每条曲线包含共用的 `η=0` 基线。
2. `frozen_criterion.json` 的 digest 仅封装模型参数，不含时间戳，重跑结果一致。
